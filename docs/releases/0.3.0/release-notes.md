### MCP-01: MCP server for coding agents

Result 01M4VX9QQ00PZP5P0VWP2E9R54 (completed), recorded 2026-10-14 00:34 UTC. The estate has a Model Context Protocol server. Vericairn.Mcp implements the protocol subset an agent harness needs (initialize with revision negotiation, ping, tools/list, tools/call) over newline-delimited JSON-RPC 2.0 on standard input and output, in the repository without a new dependency; 'vericairn mcp serve --as <principal>' hosts it as a client of the daemon or the embedded runtime, so the daemon stays the only owner and the runtime evaluates authority behind every call. The read-only pilot merged first (Vericairn/vericairn pull request 22 as d83696b53d5c) with ten read tools: health, status, check, brief, observe, record, decisions, decision, releases, devices. The second step (pull request 23 as 2d2169df2346) added work_attempt, work_result and work_amend, listed only when the acting principal has an admitted device whose key this machine holds; the runtime signs and validates each record as it does for the command line, and a refused write returns the runtime's findings as an error result. Discovery hides what the connection cannot use rather than refusing it; every tool and server text describes and never directs, and the tests assert that. 'vericairn mcp orientation' generates AGENTS.md with CLAUDE.md and GEMINI.md pointer files and an agent matrix from the estate's records; the files for the first-party estate live at the product repository's root until the estate layout admits them. tests/mcp-peer/mcp_peer.py is the independent peer. Outputs are the product files by hash; locations are paths in the Vericairn/vericairn repository.

Limitations recorded:
- Transport: stdio only; no HTTP transport, resources, prompts or sampling; the server trusts the operating-system identity of whoever runs it and is not a network service.
- Writes are limited to attempts, results and amendments; there is no tool that publishes, spends, administers devices, runs a command or authors an arbitrary record type, by design.
- No agent harness session has been observed; the agent matrix is all non-claims.
- The orientation files' 'current work' section is a snapshot of the estate at generation; they are regenerated at each release, and a stale copy says its date.
- The qualification is a verification record; the qualification record type arrives with record format 2 at M3.
