# Record reference, Vericairn 0.5.2

Generated by the build tooling (`vericairn-docs generate`) from the record type registry of build 0.5.2-dev+00021aad76c2c9d08625bb7b06b988b695aa4de2 on 2026-10-15. Each type lists its subject rule and its body fields with the field's kind, whether it is required, the record format that introduced it when that is later than format 1, and what it means. The envelope every record shares (format, type, id, at, by, body, hash and optionally subject, supersedes and signatures) is described in the record format document (record-format.md).

## `roster`

Who fills each role of the estate's work, in order of preference: planner, builder, reviewer, evaluator, release manager, publisher and decider, or a role the estate names. Agents where available, people where needed; a role with no available principal becomes an ask, never a silent fallback.

| Field | Kind | Required | Meaning |
|---|---|---|---|

## `verification`

A check of an exact subject (a repository resource, a result or a release) at an exact commit: the method, the command, the environment, who performed it, the observed result, evidence and limitations. Evidence, never permission; historical once the subject changes.

Subject: required, pinned to an exact hash.

| Field | Kind | Required | Meaning |
|---|---|---|---|
| `method` | `string` | required | How the check was performed: command, github-actions, manual, or a named tool. |
| `commit` | `hex` | required | The exact commit checked (40 hex digits). |
| `command` | `string` | optional | The command run, when the method is a command. |
| `environment` | `object` | required | Where it ran: platform, tool versions, runner; string values only, never machine paths. |
| `role` | `self|independent-agent|operator|automation` | required | self, independent-agent, operator or automation. |
| `outcome` | `passed|failed|unknown` | required | passed, failed or unknown. |
| `summary` | `string` | required | What was observed. |
| `exitCode` | `integer` | optional | Process exit code, when a command ran. |
| `durationMs` | `integer` | optional | How long the check took. |
