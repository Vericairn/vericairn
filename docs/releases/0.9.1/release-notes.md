## Security

Vericairn 0.9.1 corrects two weaknesses: one in the .NET runtime every 0.9.0 distributable embeds, and one in how a Codex worker run keeps Vericairn's MCP server apart from the run's own directory. Neither lets anyone sign a record without an admitted device or act as another principal.

**The distributables embedded a .NET runtime with published advisories (0.9.0 and earlier; FIX-91).** Every 0.9.0 command line and Workbench archive embeds .NET and ASP.NET Core runtime 10.0.11, which Microsoft's advisories published since then affect, two of them rated critical for ASP.NET Core. Vericairn's daemon serves its API through ASP.NET Core on the local socket or named pipe, on loopback with device-signed requests, and, when configured, on the local-network listener with mutual TLS to paired devices; in the default configuration no unauthenticated network path reaches it. In 0.9.1 every distributable is built on .NET SDK 10.0.403 and embeds runtime, ASP.NET Core and apphost 10.0.14, which fixes those advisories; the release's bill of materials lists the embedded packs. The NuGet tool uses the .NET runtime installed with the SDK, which its user keeps current.

**A worker run could hand Vericairn's MCP server the run's own temporary directory (0.9.0; FIX-88).** 0.9.0 gives each run its own temporary directory and keeps the user's for Vericairn's MCP server, which runs outside the harness's sandbox. When the worker's environment named no temporary directory, as is common on Linux, the server's environment named none either, and a harness that passes its own environment to the servers it starts could give the server the run's directory, where the agent can write. In 0.9.1 the server's temporary variables are always set, from the worker's environment or else the worker's resolved temporary directory, and never to the run's own temporary directory or a path inside it; dispatch and harness qualification share the configuration. A qualification recorded on Linux without a temporary directory in the worker's environment must be redone.
