# FIX-178: Preserve unreadable Secure Enclave runtime identities

## docs/operator-guide.md

### In "19. Pairing, local-network connections and revocation", after the paragraph beginning "Revocation is checked on the next request"

> From 0.9.5 (FIX-178), startup of the local-network profile preserves a saved Secure Enclave runtime identity
> when its key cannot be read. Startup refuses and gives a remedy for the failure. Use the original Mac if this Mac cannot open the key, or restore the
> missing key blob on the original Mac. To keep serving here with a new identity, stop the runtime and run
> `vericairn runtime rotate --identity --replace-unreadable` with a working Secure Enclave helper. Start the runtime
> again after rotation. Every paired device must pair again.
