# FIX-158: Check a record's body before asking for a signature

## docs/operator-guide.md

### In "Presence prompts, announced and counted (0.9.3)", after the paragraph beginning "Up to 0.9.3 a device"

> From 0.9.5 (FIX-158), a single-record write such as `records new` or `work assign` checks the body's fields, types, lengths and
> record-specific rules before asking the signing device. A body error is reported without a presence prompt. After signing, the
> runtime still judges the proposed record against the current estate under the write lock before it stores it.
