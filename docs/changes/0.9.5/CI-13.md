# CI-13: Exercise public example estates against the candidate

## docs/limitations-and-platforms.md

### Add an examples smoke entry with the continuous integration coverage

> From 0.9.5, CI checks that each public example pin is reachable from its repository's default branch. It uses the checksummed
> command line to check the pinned estate and plan a read-only upgrade, and checks the README's release references and relative
> links. Registered journeys use an in-process driver with a controllable clock or the published archive with instant timing.
> CI builds the journey driver before starting the archive smoke.
> The archive driver previews agent steps and runs the people-only variant. The in-process tier exercises dispatch with executable
> stand-in harnesses. Dispatch from a shipped build is part of the live release preparation because CI cannot make a presence cut.
