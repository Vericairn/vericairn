# Security

## Reporting a vulnerability

Report a security problem privately, never in a public issue or pull request. Use GitHub's private vulnerability
reporting: on this repository's **Security** tab, choose **Report a vulnerability**. If you cannot use it, email
vericairn@jasonfurr.com.

Say what you found, the release or commit it affects, and how to reproduce it. The maintainer reads every report.
Vericairn has no support commitment yet, so no response time is promised.

## What this covers

The code in this repository and the releases published from it on GitHub Releases. Every release is an unsigned
developer build, and its documentation set lists its known limitations.
